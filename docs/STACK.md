# Стек технологий

## Backend

| Компонент | Технология | Почему |
|-----------|-----------|--------|
| API Framework | **FastAPI** | Async, автогенерация OpenAPI/Swagger, Pydantic валидация, dependency injection |
| ORM | **SQLAlchemy 2.0** | Async support, type hints, зрелая экосистема |
| Миграции | **Alembic** + psycopg3 | psycopg2 несовместим с Windows cp1251 локалью |
| БД | **PostgreSQL 16** | JSONB, полнотекстовый поиск, ON CONFLICT upsert, надёжность |
| Кэш | **Redis 7** | Кэш запросов, сессии, rate limiting |
| Валидация | **Pydantic v2** | Быстрая, type-safe, интегрирована с FastAPI |
| Логирование | **structlog** | Структурированные логи, JSON output для production |
| HTTP клиент | **aiohttp** (MOEX), **httpx** (внутренний) | aiohttp — для потокового получения данных, httpx — для API-to-API |
| Конфигурация | **pydantic-settings** | Типизированное чтение из .env |
| Данные | **MOEX ISS** (котировки + description эмитентов) | Официальный бесплатный API без ключей; этапы 2-4 риск-сигналов добавят АКРА/Эксперт РА/e-disclosure/Федресурс/ГИР БО (см. docs/RISK_SIGNALS_PLAN.md) |

## Frontend

| Компонент | Технология | Почему |
|-----------|-----------|--------|
| Фреймворк | **React 18** + TypeScript | Компонентный подход, типизация, огромная экосистема |
| Сборщик | **Vite** | Быстрый HMR, простая конфигурация |
| Стилизация | **Tailwind CSS** | Utility-first, быстрая разработка, консистентный дизайн |
| Компоненты UI | **shadcn/ui** | Не библиотека, а копируемые компоненты. Полный контроль, accessible |
| Таблицы | **TanStack Table** | Headless, фильтрация/сортировка/пагинация на сервере |
| Графики | **Recharts** | Простой API, хорошо интегрируется с React |
| Роутинг | **React Router v6** | Стандарт для SPA |
| HTTP клиент | **axios** или **fetch** + react-query | Кэширование запросов, дедупликация, stale-while-revalidate |
| Состояние | **TanStack Query (react-query)** | Серверный стейт — в react-query, локальный — в useState/Zustand |
| Иконки | **Lucide React** | Лёгкие, консистентные |

## Принципиальные решения

### Почему React, а не Next.js
Наш фронтенд — чистый SPA. Нам не нужен SSR (контент не индексируется поисковиками — это приватный скринер за авторизацией). Next.js добавил бы сложность без пользы. React + Vite проще, быстрее собирается, меньше магии.

### Почему не Django
FastAPI уже написан и работает. Django хорош для full-stack, но у нас раздельные фронтенд и бэкенд. FastAPI лучше для API-first архитектуры: async из коробки, автодокументация, Pydantic.

### Почему TanStack Query, а не Redux
Почти весь стейт приложения — серверный (список облигаций, детали, фильтры). TanStack Query создан именно для этого: кэширование, фоновое обновление, дедупликация запросов. Redux был бы оверкилл.

### Почему shadcn/ui, а не Material UI / Ant Design
shadcn/ui — это не npm-пакет, а набор компонентов которые копируются в проект. Полный контроль над стилями, нет vendor lock-in, работает на Tailwind. Дизайн современный и чистый — как у Snowball Income.
