## Ядро (Backend)

### ✅ MOEX Data Collector
Автоматический сбор данных облигаций с Московской биржи через ISS API.
- Три борда: TQCB (корпоративные), TQOB (ОФЗ), TQIR (муниципальные)
- ~3000 облигаций за 25 секунд
- Bulk upsert батчами по 500
- Режим одноразового запуска и бесконечного цикла
- **Файлы:** `src/collector/moex_client.py`, `src/collector/repository.py`, `src/collector/main.py`

### ✅ REST API — Скрининг облигаций
Фильтрация, сортировка, пагинация облигаций.
- Фильтры: цена, доходность, купон, дни до погашения, квал. статус, тип, листинг, борд
- Сортировка по любому полю (asc/desc)
- Пагинация (page, per_page)
- **Эндпоинт:** `GET /api/v1/bonds`
- **Файлы:** `src/api/router.py`, `src/api/service.py`, `src/api/schemas.py`

### ✅ REST API — Детали облигации
Полная информация по конкретной бумаге.
- **Эндпоинт:** `GET /api/v1/bonds/{secid}`

### ✅ REST API — Обзор рынка
Агрегированная статистика по рынку облигаций.
- Количество по типам, средняя доходность, средний купон, средняя дюрация
- **Эндпоинт:** `GET /api/v1/stats/market-overview`

### ✅ База данных
PostgreSQL 16 с нормализованной схемой.
- Таблицы: bonds, users, user_filters, payments
- Alembic миграции через psycopg3
- Async session через asyncpg
- **Файлы:** `src/db/models/`, `src/db/migrations/`, `src/db/session.py`

## Веб-интерфейс (Frontend)

### 📋 Скринер облигаций
Главная страница. Таблица облигаций с боковой панелью фильтров.
- Таблица с колонками: название, тикер, цена, доходность, купон, дни до погашения, листинг
- Панель фильтров: диапазоны (от-до), чекбоксы, выпадающие списки
- Сортировка по клику на заголовок колонки
- Пагинация
- Быстрый поиск по названию/тикеру
- **Дизайн:** вдохновлён Snowball Income — чистый, профессиональный, тёмная/светлая тема

### 📋 Карточка облигации
Детальная страница одной облигации.
- Все данные: цена, доходность, купон, НКД, номинал, лот, дюрация, оферта
- График цены (история)
- Купонный календарь
- Сравнение с похожими бумагами

### 📋 Дашборд (обзор рынка)
Аналитическая страница.
- Распределение облигаций по типам (pie chart)
- Средние показатели рынка
- Топ по доходности / купону
- Новые выпуски

### 📋 Лендинг
Страница для привлечения пользователей.
- Описание продукта
- Преимущества
- Тарифы
- CTA → регистрация

## Авторизация и монетизация

### 📋 Регистрация и авторизация
- Email + пароль
- JWT токены (access + refresh)
- OAuth (Google, Яндекс) — опционально

### 📋 Тарифные планы
- **Бесплатный:** ограниченные фильтры, 10 результатов, без экспорта
- **Про:** все фильтры, без ограничений, экспорт, уведомления
- **Бизнес:** API доступ, массовый экспорт

### 📋 Платежи
- Интеграция с ЮKassa или Stripe
- Управление подписками
- История платежей

## Продвинутые фичи

### 💡 Избранное
Сохранение облигаций в watchlist. Отслеживание изменений.

### 💡 Уведомления
Алерты при изменении цены/доходности выбранных бумаг. Email или push.

### 💡 Экспорт в Excel
Выгрузка отфильтрованных облигаций в .xlsx файл.

### 💡 Сравнение облигаций
Выбор 2-5 бумаг для side-by-side сравнения.

### 💡 Купонный календарь
Календарь предстоящих купонных выплат по выбранным бумагам.

### 💡 Рейтинги эмитентов
Агрегированная оценка надёжности эмитента на основе данных MOEX.

### 💡 История цен
График исторических цен и доходности облигации.

## Инфраструктура

### ✅ Docker Compose
PostgreSQL 16 + Redis 7 для локальной разработки.

### 📋 Redis-кэш для API
Кэширование результатов фильтрации, TTL 5 минут.

### 📋 CI/CD Pipeline
GitHub Actions: lint → test → build → deploy.

### 📋 Kubernetes
Деплой в production. Helm charts, HPA, secrets.

### 📋 Мониторинг
Prometheus + Grafana. Метрики: latency, error rate, количество запросов.
