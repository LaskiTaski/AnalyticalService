# Архитектура фронтенда

## Принципы

1. **Фронтенд не считает** — все расчёты, фильтрация, сортировка, агрегация выполняются на бэкенде. Фронтенд получает готовые данные и отрисовывает.
2. **Server state ≠ client state** — данные с сервера живут в TanStack Query (кэш, фоновое обновление). Локальный UI-стейт (модалки, формы) — в useState/Zustand.
3. **Типизация везде** — TypeScript strict mode. API-типы генерируются из OpenAPI схемы.
4. **Компоненты владеют своим стилем** — Tailwind CSS утилиты, никаких глобальных CSS файлов (кроме переменных темы).

## Риск-сигналы эмитента в UI (этап 1)

- **Таблица скринера:** точка-индикатор рядом с названием бумаги
  (жёлтая — есть события, красная — тяжёлые: default / tech_default /
  bankruptcy_intent / restructuring), тултип с количеством.
- **BondDrawer:** вкладка «Эмитент» (`IssuerTab.tsx`) — карточка эмитента
  (название, ИНН, ОКПО, число бумаг), лента событий с бейджами типов и
  ссылками на первоисточники; на табе — точка-индикатор, при тяжёлых
  событиях на всех вкладках виден красный баннер-переход.
- **FilterChips:** чип «Риск-сигналы» (красный оттенок), чекбокс «Только
  с риск-сигналами» → `?risk=1` в URL → `risk_only=true` в API.
- Метаданные типов событий (подписи, тяжесть) — `EVENT_META` в `IssuerTab.tsx`;
  при подключении этапов 2-3 новые типы добавляются там же.

## Data Flow

```typescript
// 1. Пользователь меняет фильтр
const [filters, setFilters] = useFilters() // синхронизирует с URL search params

// 2. TanStack Query автоматически делает запрос
const { data, isLoading } = useQuery({
  queryKey: ['bonds', filters],
  queryFn: () => api.getBonds(filters),
  keepPreviousData: true, // показывает старые данные пока грузятся новые
})

// 3. Компонент отрисовывает
<BondTable data={data.items} loading={isLoading} />
```

## Дизайн-система

Направление: «глубокий изумруд + малина» — тёмная база с зелёным подтоном,
фирменный изумрудный герой-блок и малиновый акцент действий.

- **Палитра:** база `#0c0f0e` (тёмная) / `#f2f5f3` (светлая); герой —
  изумрудный градиент `#17795c → #0e4a38 → #0a3a2c`, одинаковый в обеих темах
  (бренд-константа, как логотип); акцент `#e21b5a` (малина); метрики:
  teal `#2ec99e` — хорошо, олива `#8a8420` — средне, роза `#c2405c` — плохо.
- **Типографика:** заголовки — Inter Tight 800 (плотный жирный гротеск),
  текст/UI — Golos Text, данные — JetBrains Mono.
- **Формы:** пилюли (rounded-full) для чипсов, бейджей, кнопок навигации;
  карточки rounded-xl/2xl.
- **Токены:** `lib/theme.ts` — Tokens (тема) × AccentStyle (акцент,
  по умолчанию «малина», переключается в шапке). Герой — поля
  `hero / onHero / heroInput / heroChip` в Tokens.
- **Анимации:** минимальные — drawer, попапы чипсов, скелетоны;
  отключаются при prefers-reduced-motion.

## Взаимодействие с API

```typescript
// api/client.ts
const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL || 'http://localhost:8000',
})

// api/bonds.ts
export const getBonds = (params: BondFilterParams) =>
  api.get<BondListResponse>('/api/v1/bonds', { params })

export const getBond = (secid: string) =>
  api.get<BondResponse>(`/api/v1/bonds/${secid}`)

export const getMarketOverview = () =>
  api.get<MarketOverview>('/api/v1/stats/market-overview')

// api/issuers.ts — риск-сигналы эмитента
export const getIssuer = (inn: string) =>
  api.get<Issuer>(`/api/v1/issuers/${inn}`)

export const getIssuerEvents = (inn: string) =>
  api.get<IssuerEventsResponse>(`/api/v1/issuers/${inn}/events`)
```

## Фильтры через URL

Фильтры хранятся в URL search params. Это позволяет:
- Делиться ссылкой с настроенными фильтрами
- Работать кнопка "Назад" в браузере
- Bookmarking конкретных настроек

```
/screener?yield_min=10&days_max=365&type=corp&sort=yield_at_prev_wa_price&order=desc
```
